Tạo QR cơ bản

Mẫu nhanh tạo một QR riêng. Bạn có thể xem lệnh, tải PNG hoặc xuất bản như cấu hình thường.

Để dừng ghi bằng QR, quét mẫu “Cho phép quét khi đang quay” trước khi bắt đầu ghi (QRDR, áp dụng trong phiên bật máy).

Chủ sở hữu & ngày giờ trên video

OWNR được lưu lâu dài, hiện khi bật máy và nằm trong metadata của ảnh/video. Tối đa 64 ký tự không dấu (\n tính 2 ký tự); Enter để xuống dòng.

BURN ghi chữ trực tiếp vào video, không thể gỡ khỏi video đã quay. HERO10–13: chỉ 8-bit, 4K 16:9 ≤30fps, 2.7K ≤60fps, 1080p ≤120fps. Hỗ trợ tùy camera/firmware; chọn 8-bit trong Protune khi dùng overlay.

Xuất bản cho mọi người

Lưu cấu hình vào GitHub để cập nhật trang quét.

Trang quản trị mở công khai. Chỉ người có token được cấp quyền ghi repo mới có thể xuất bản. Token chỉ dùng cho lần gửi này.

Xem GitHub Actions ↗
Thiết lập GitHub Pages lần đầu

Đẩy source lên nhánh main, mở Settings → Pages → Source → GitHub Actions. Workflow có sẵn sẽ build và deploy khi push hoặc khi xuất bản cấu hình tại đây.

Tạo fine-grained token chỉ cho repository này, quyền Contents: Read and write. Không đưa token vào source hoặc file cấu hình.
